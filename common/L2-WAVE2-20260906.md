## Supported functions and profiles

The supported kernel functions are `__get_unaligned_be24`,
`__get_unaligned_le24`, `__put_unaligned_be24` and `__put_unaligned_le24` in
`include/linux/unaligned.h`. The two `fragma_roundtrip_*24` functions are project
witnesses, not kernel functions. Twenty-four profile/function combinations
remain four distinct kernel functions.

| Target suffix in `common.unaligned24.*` | Exact profile | C data model / endian | Genuine inline policy |
| --- | --- | --- | --- |
| `arm` | `arm-gcc` | ILP32 / little | `no-instrument` |
| `powerpc32` | `powerpc32-gcc` | ILP32 / big | `patchable-entry-0` |
| `m68k` | `m68k-gcc` | ILP32 / big | `no-instrument` |
| `arm64` | `arm64-gcc` | LP64 / little | `no-instrument` |
| `riscv64` | `riscv64-gcc` | LP64 / little | `no-instrument` |
| `sh` | `sh-gcc` | ILP32 / little | `no-instrument` |

The [unchanged contracts](annotated/unaligned24.verified.c) require only three
readable or writable bytes. Writers accept every `u32`; round trips recover
the input modulo 2^24. There is no extra alignment, buffer extent or value
restriction. Exact kernel bodies/declarators, six analyzed bodies, both typedefs,
24 ordered ACSL blocks and 16 intermediate assertions are retained per profile.
All selected memory, pointer-formation, shift and direct-call obligations pass,
with unconditional dependency closure and no omitted or trusted proof dependency.
Analysis tools and the explicitly reviewed model assumptions remain trusted.
