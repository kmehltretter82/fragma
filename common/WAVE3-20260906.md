# Common24 wave three — Alpha, x86-64 and UML

The third wave registers `common.unaligned24.alpha`,
`common.unaligned24.x86_64` and `common.unaligned24.um-x86_64` under their
separate configured GCC profiles. The registry now contains 31 targets,
21 architecture families and still 24 distinct kernel functions. Repeating
the same four byte helpers across profiles adds no distinct kernel functions.

The [scoped review](REVIEW-WAVE3-20260906.md) records the full domains,
profile-specific type/frontend assumptions, exact five diagnostics per new
profile, narrow Alpha metadata recognition and genuine `-Os` support. It
explicitly renews the provider review for the older six common24 contexts;
their original assumption scopes remain unchanged. Review alone does not
accept saved results or award an architecture level.

  No source or compiler argument is replaced. All 22 wrong-expectation errors
  and both genuine-header mismatch controls remain mandatory.
